GIFmaker Privacy Policy

Last updated: October 13, 2026

GIFmaker is designed as a local-first GIF creation app. The app does not require an account and does not use advertising identifiers or cross-site tracking.

Photos

GIFmaker asks permission to select photos and to save exported GIFs. Selected photos are processed on your device to create the GIF file.

GIF Library

The built-in GIF Library is included in the app. Browsing, searching, previewing, and importing these samples work locally without internet access. If you choose "Search GIFs on the web", GIFmaker displays a third-party search page inside the app using your current search term. Automatic mode selects Baidu Images for mainland China and Bing Images elsewhere, based on your device region or an optional network country lookup. You can also select either provider manually. Web pages, including search result links, remain inside the app. Online results are not automatically added to the built-in library.

Search Region Selection

Automatic search selection uses your device's region setting by default. You can enable "Use network region" after agreeing to the country lookup notice in the app. Only when that option is enabled and Automatic is selected does GIFmaker request a country code from IPWHOIS.IO at ipwho.is over HTTPS. This provider receives your network IP address as part of the request; GIFmaker does not send your search term, photos, or exported GIFs to this lookup service. No GPS or device location permission is used. If detection fails, GIFmaker uses your device's region setting. A VPN or proxy can affect the network region. Manual provider selection skips the lookup and is saved locally. You can turn network detection off at any time. Search cookies and website data use a temporary web session.

iCloud

After an export, history stores the GIF and an editable project containing the original frame images, captions, colors, borders, timing, and canvas settings. If iCloud is available on your device, these files and their history index are saved in your private iCloud container so they can be available on your other devices using the same Apple Account. If iCloud is unavailable, the history is stored in the app's local application support folder. Deleting a history record also removes its stored editable project. Unsaved editing sessions are not stored in history.

Data Collection

GIFmaker does not operate a server that collects your photos or exported GIFs. GIF files are created locally and are only shared when you choose to use the system share sheet, save them to Photos, or store them in your private iCloud container. Optional online searches send your search terms to the selected search provider. Downloading a GIF requests the selected image from its hosting website. The search provider and websites you visit or download from receive normal web request information, including your IP address. Search and network region lookup providers handle those requests under their own privacy policies.

Tracking

GIFmaker does not track you across apps or websites.
